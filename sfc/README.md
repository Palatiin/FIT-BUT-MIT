# Soft Computing
## Project: Demonstration of Autoencoder Deep Neural Network Learning

### Installation
```bash
pip3 install -r requirements.txt
```

### Run
1. Download the dataset
2. Run the server: `python3 app.py`
3. Open `http://127.0.0.1:5000/` in your browser
4. - Configure -> Train -> Test the model

### Dataset
Source: https://www.fit.vutbr.cz/study/courses/SFC/private/benchmarks/mnist/mnist.zip
